# java-filmorate

Учебный backend-проект на Java и Spring Boot: сервис для работы с фильмами, оценками пользователей и возврата топ-5 фильмов, рекомендованных к просмотру.

Проект развивается поэтапно. На текущем этапе реализован базовый каркас Spring Boot приложения, REST API для управления пользователями и фильмами, in-memory хранилище и строгая валидация данных.

## Ключевые возможности на данном этапе

- CRUD-операции для `Film` и `User` (создание, обновление, получение списка).
- Хранение данных в оперативной памяти (`HashMap`).
- Автоматическая генерация уникальных идентификаторов.
- Строгая валидация входящих данных через `spring-boot-starter-validation` (`@Valid`, `@NotBlank`, `@Email`, `@Positive` и др.).
- Кастомная бизнес-валидация (проверка даты релиза кино, запрет пробелов в логине, автозамена пустого имени на логин).
- Обработка ошибок через кастомное исключение `ValidationException`.
- Логирование всех ключевых операций и ошибок с помощью `SLF4J`.
- Покрытие бизнес-логики и граничных условий unit-тестами.

## Технологии

- **Java 21**
- **Spring Boot 3.2.2**

    - `spring-boot-starter-validation` (Валидация данных)

- **JUnit 5** (Unit-тестирование)

## Запуск проекта

1. Склонировать репозиторий.
2. Открыть проект в **IntelliJ IDEA**.
3. Дождаться загрузки зависимостей Maven.
4. Запустить метод `main` в классе `FilmorateApplication`.

После запуска сервер будет доступен на порту **8080**.

Для проверки HTTP-запросов можно использовать **Postman** (в корне проекта или в материалах курса доступна готовая коллекция тестов `postman.json`).

## Основные HTTP-эндпоинты

### Фильмы (`/films`)
- `GET /films` — получить список всех фильмов.
- `POST /films` — добавить новый фильм.
- `PUT /films` — обновить существующий фильм.

### Пользователи (`/users`)
- `GET /users` — получить список всех пользователей.
- `POST /users` — создать нового пользователя.
- `PUT /users` — обновить данные существующего пользователя.

## Реализация по этапам

<details open>
<summary><strong>Этап 1 — Каркас Spring Boot приложения и базовый REST API</strong></summary>

На этом этапе был заложен фундамент будущего сервиса рекомендаций фильмов. Проект переведен на рельсы Spring Boot, реализованы базовые модели данных и контроллеры.

**Что сделано:**
- Настроен `pom.xml`, подключены необходимые стартеры Spring Boot, Lombok и плагин Checkstyle.
- Созданы модели данных `Film` и `User` с использованием аннотаций Lombok (`@Data`).
- Реализованы REST-контроллеры `FilmController` и `UserController`.
- Настроено in-memory хранение данных с ручной генерацией ID.
- Добавлена валидация данных через аннотации `jakarta.validation.constraints`.
- Реализована сложная бизнес-валидация (например, дата релиза фильма не может быть раньше 28 декабря 1895 года).
- Настроено логирование запросов и ошибок.
- Написаны unit-тесты для проверки логики валидации контроллеров.

**Ключевые решения:**
- Использование `spring-boot-starter-validation` позволило значительно сократить количество ручных проверок `if-else` в контроллерах и сделать код чище.
- Выделение кастомного исключения `ValidationException` подготовило почву для будущего создания глобального обработчика ошибок (`@ControllerAdvice`).
- Разделение логики валидации и сохранения данных внутри контроллеров делает код читаемым и легко тестируемым.
